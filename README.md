# Explora Guayaquil - Agencia de Turismo Ficticia

## Información del Estudiante
* **Nombre:** Mario Avelino Rivas Zambrano
* **Lugar Turístico Asignado:** Guayaquil - Provincia del Guayas
* **Enfoque:** Turismo urbano, patrimonio colonial, gastronomía local y parques naturales.

## Descripción del Proyecto
Sitio web responsivo desarrollado como examen práctico final para la asignatura de Diseño de Sitios Web. Promociona los principales atractivos turísticos, actividades culturales y oferta gastronómica de la ciudad de Guayaquil.

## Tecnologías Utilizadas
* HTML5 (Estructura semántica y formularios)
* CSS3 (Flexbox, CSS Grid, Media Queries, Box Model)
* Git y GitHub (Control de versiones)
* GitHub Pages (Despliegue web)
